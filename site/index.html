Method and caveats

How the results are produced, what guards against fooling ourselves, and what the numbers can't tell you.

Reproduce these results

python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python export_results.py --as-of 2026-10-23
python -m http.server -d site 8000   # then open http://localhost:8000

Data comes from Yahoo Finance (silver and gold futures), FRED (real rates, breakeven inflation, dollar index, T-bill rate) and the CFTC (Commitments of Traders). Downloads are cached by date, so a pinned --as-of run reads identical data every time.

Safeguards

  • No lookahead. Each macro series is aligned to the date it was published, not the date it describes: daily yields one business day later, the weekly dollar index the Tuesday after its Monday release, COT reports after their Friday release.
  • Purged walk-forward. Each refit trains only on labels whose 21-day window ends before the test date. Lasso and ElasticNet use the same gap inside their own cross-validation.
  • Independent test points. Forecast targets and VaR windows never overlap, so every test has the independent samples it assumes.
  • Out-of-sample risk backtests. Each day's VaR is calibrated on the previous 504 trading days only, and breaches are measured as a share of position value, not in dollars.
  • Multiple comparisons. With 40 model × horizon cells and two tests each, a few raw p < 0.05 hits are expected by chance. Results are adjusted with Bonferroni, Holm and Benjamini-Hochberg.

Known limitations

  • SI=F is a continuous front-month series with no roll adjustment, so roll dates add small artificial returns. Listed options are on a specific contract month.
  • Option prices use a GARCH forecast as a stand-in for implied volatility.
  • The Student-t degrees of freedom (5) and the jump threshold (4 local standard deviations) are fixed, not estimated.
  • COT releases shift by a day in holiday weeks; alignment uses the normal schedule.
